# Python Data Processor

A lightweight Python application for computing statistical summaries of numerical datasets.

## Features
- Calculates mean, median, min, max, and standard deviation.
- Standalone execution with zero external dependencies (uses standard library).

## Prerequisites
- Python 3.8 or higher.
